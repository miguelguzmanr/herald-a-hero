# Herald a Hero

Herald a Hero is a hero builder for Herald's Decree, a tabletop RPG by [Milestone Play](https://milestoneplay.com/).

[![License: GPL v3](https://img.shields.io/badge/license-GPL--3.0-blue.svg)](./LICENSE)

## Development

Herald a Hero is written in TypeScript, using Vite and Svelte.

### Getting Started

Requires Deno 2.9 or later.

```sh
deno install && deno task dev
```
