# Herald a Hero

Herald a Hero is an unofficial hero builder for Herald's Decree, a tabletop RPG by [Milestone Play](https://milestoneplay.com/).

[![CI](https://github.com/miguelguzmanr/herald-a-hero/actions/workflows/ci.yml/badge.svg)](https://github.com/miguelguzmanr/herald-a-hero/actions/workflows/ci.yml)
[![License: GPL v3](https://img.shields.io/badge/license-GPL--3.0-blue.svg)](./LICENSE)
[![Live app](https://img.shields.io/badge/live-herald--a--hero.miguelguzman.dev-orange)](https://herald-a-hero.miguelguzman.dev)

You can try it live at [herald-a-hero.miguelguzman.dev](https://herald-a-hero.miguelguzman.dev).

## Development

Herald a Hero is written in TypeScript, using Vite and Svelte.

### Getting Started

Requires pnpm and Node.js 26 or later.

```sh
pnpm install && pnpm dev
```
